Windows 3.1 (1992)

Дата: 1992 год

Разработчик: Microsoft

Описание: Выпуск Windows 3.1. Эта графическая оболочка для MS-DOS стала массовой благодаря улучшенной стабильности, поддержке мультимедиа и шрифтов TrueType.

Новые возможности:

  • Улучшенный графический интерфейс
  • Поддержка шрифтов TrueType
  • Мультимедийные расширения (Windows 3.1 Multimedia Extensions)
  • Улучшенная поддержка сетей
  • Более стабильная работа по сравнению с Windows 3.0

Культурное влияние: Windows 3.1 стала первой версией Windows, получившей массовое распространение, и заложила основы для будущего доминирования Windows на рынке операционных систем.

Видеоинструкция по установке

Краткая справка: После загрузки в командной строке DOS введите команду WIN /S для запуска Windows 3.1.
